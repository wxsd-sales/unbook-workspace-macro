Unbook Workspace Macro

Booking Monitor Profiles

Profiles decide how different bookings are handled. Each incoming booking is matched against these profiles in order, and the first match determines whether and how the workspace is monitored for presence. Keep a Default profile last as a catch‑all.

Presence Detection Sensors

Choose which signals count as someone being present in the workspace. If any enabled signal reports presence, the booking is kept; when none do, the unbooking countdown begins.

Active Calls Treat an active call (including Microsoft Teams) as presence.
Presentation Treat an active local or shared presentation as presence.
People Count Treat a room analytics people count above zero as presence.
People Presence Treat the people presence detector (ultrasound / head detection) as presence.
GUI Interactions Treat touch panel and widget interactions as presence.

External Logging

Optionally send a notification each time the macro unbooks a workspace, either to a Webex space / person via a bot, or to your own webhook endpoint.

Enable External Logging When off, actions are only logged to the device console.
For a Webex Bot use https://webexapis.com/v1/messages. For a webhook use your own endpoint URL.
Create a Webex Bot and copy its access token from developer.webex.com/my-apps.
Debugging Mode Log the actions the macro would take without actually declining or deleting bookings.
